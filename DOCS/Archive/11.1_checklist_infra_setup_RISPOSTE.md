## E. Riepilogo — cosa sblocca cosa

```
A2 (URL workspace)    ──► terraform plan / apply
A1 (backend state)    ──► terraform init
A4 (gruppi UC)        ──► terraform apply (grants)
A3 (SKU VM)           ──► terraform apply (cluster policy)
B1 (repo GitLab)      ──► apertura MR con brownfield/
B2 (secrets GitLab)   ──► pipeline CI/CD attiva
C1 (push mechanism)   ──► primo file reale su landing → primo run bronze
C2 (SLA push)         ──► scheduling definitivo workflow
```

**Sequenza minima per il primo `terraform apply`:**  
A2 → A1 → `terraform init` → A4 + A3 (in parallelo) → `terraform apply` → B1 (MR).

**Sequenza minima per il primo run Bronze su cloud:**  
Terraform apply fatto + B2 (secrets) + C1 (push mechanism confermato) + C3 (path confermato).
